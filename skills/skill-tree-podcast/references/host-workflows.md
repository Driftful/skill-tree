# Host Workflows

This document is for podcast hosts and maintainers working through agents.

## What This Covers

- Guest profile creation and updates.
- Episode transcript processing and formatting.
- Episode metadata updates.
- Build and publish/deploy scripts for GitHub.

## Maintenance Expectations

- Keep source content (`episodes`, `speakers`, `transcripts`, topic definitions) current and consistent.
- Regenerate index and aggregation pages as part of normal publishing.
- Ensure root `SKILL.md` continues to act as a concise navigation hub.

## Authoring Guidance

- Prefer structured metadata that supports query-style retrieval by agents.
- Keep summaries scannable and tags accurate.
- Link speakers, topics, and episodes consistently so aggregation remains reliable.
